# Мои расходы

Простая страница для личного учёта расходов за месяц. Работает локально в браузере и не отправляет данные в интернет.

## Что умеет

- Добавлять трату с суммой, категорией, датой и необязательным комментарием.
- Показывать новые траты сверху списка.
- Считать итог только за текущий календарный месяц.
- Сохранять траты в `localStorage`, чтобы они оставались после F5.
- Проверять сумму и не сохранять пустые, неверные, нулевые или отрицательные значения.

## Как открыть

Откройте `index.html` двойным щелчком. Интернет и установка программ не нужны.

## Как проверить

1. Добавьте траты `5 000`, `2 500` и `12 000` с датами текущего месяца. Итог должен стать `19 500 ₸`.
2. Убедитесь, что последняя добавленная трата находится сверху списка.
3. Добавьте трату с датой другого месяца. Она должна появиться в списке, но не изменить итог текущего месяца.
4. Попробуйте пустую сумму, `0`, отрицательное и дробное значение. Трата не должна сохраниться, должна появиться подсказка, а `NaN` не должен отображаться.
5. Добавьте трату без комментария. Пустая строка комментария не должна показываться в записи.
6. Обновите страницу клавишей F5. Все добавленные траты и итог должны остаться на месте.
7. Проверьте страницу при ширине окна 375 px: поля и кнопка должны быть удобны для нажатия и не выходить за экран.

Деньги отображаются целыми тенге с пробелами между тысячами (`15 000 ₸`), даты — в формате `23.11.2026г.`.
