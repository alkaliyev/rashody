# 002 — Итоги по категориям

## Для кого и зачем

Для человека, который ведёт личные расходы и хочет сразу видеть, на что ушли деньги в текущем месяце. Разбивка помогает сравнить расходы на еду, транспорт, дом и другие покупки без ручного подсчёта.

## Что должно быть

- Под общим итогом за текущий месяц показывается разбивка по четырём категориям:
  - «Еда»;
  - «Транспорт»;
  - «Дом»;
  - «Другое».
- Напротив каждой категории показывается сумма трат этой категории за текущий календарный месяц.
- Категории показываются всегда в указанном порядке, даже если сумма категории равна нулю.
- В расчёт входят только траты, у которых дата относится к текущему месяцу и году.
- После добавления новой траты общий итог и итог нужной категории обновляются сразу.
- После F5 итоги по категориям восстанавливаются из сохранённых трат.
- Суммы отображаются целыми тенге с пробелами между тысячами, например `15 000 ₸`.
- Блок удобно читается на телефоне шириной 375 px и не создаёт горизонтальную прокрутку.

## Примеры

- «Еда» `5 000 ₸` и `2 500 ₸`, «Транспорт» `12 000 ₸` в текущем месяце → общий итог `19 500 ₸`, «Еда» `7 500 ₸`, «Транспорт» `12 000 ₸`, «Дом» `0 ₸`, «Другое» `0 ₸`.
- Трата «Дом» `8 000 ₸` с датой прошлого месяца остаётся в списке, но не меняет итог категории «Дом» за текущий месяц.
- Новая трата «Другое» `1 000 ₸` за текущий месяц сразу увеличивает общий итог и итог категории «Другое» на `1 000 ₸`.

## Ограничения

- Использовать только HTML, CSS и JavaScript без библиотек, npm и внешних ресурсов.
- Данные по-прежнему хранятся только в `localStorage` и никуда не отправляются.
- Не добавлять выбор месяца, диаграммы, проценты и новые категории.
- Не менять категории существующей формы и не ломать добавление или список трат.
- Никогда не показывать `NaN`.

## Готово, когда

- Под общим итогом видны четыре категории с суммами в правильном формате.
- Траты текущего месяца правильно распределяются по категориям, а сумма категорий равна общему итогу.
- Траты за другие месяцы не входят ни в общий итог, ни в итоги по категориям текущего месяца.
- Категория без трат показывает `0 ₸`.
- После добавления траты нужный итог обновляется без перезагрузки.
- После F5 значения сохраняются и рассчитываются правильно.
- На ширине 375 px блок полностью помещается на экране.
