# 006 — Остаток общего бюджета

## Для кого и зачем

Для человека, который хочет сразу понимать, сколько денег ещё можно потратить в текущем месяце независимо от отдельных категорий. Общий остаток сравнивает весь месячный бюджет со всеми расходами месяца.

## Что должно быть

- В разделе «За текущий месяц» рядом с общим итогом трат показывается показатель «Остаток бюджета».
- Общий бюджет равен сумме лимитов категорий «Еда», «Транспорт», «Дом», «Рассрочки» и «Другое».
- Остаток бюджета равен общему бюджету минус все траты текущего календарного месяца.
- Пока расходы не превышают общий бюджет, показывается неотрицательная сумма с подписью «Остаток бюджета».
- Если расходы превышают общий бюджет, вместо отрицательного остатка показывается заметное предупреждение «Перерасход бюджета: …» с суммой превышения.
- При общем бюджете `0 ₸` и отсутствии трат остаток равен `0 ₸`.
- При общем бюджете `0 ₸` и наличии трат текущего месяца показывается перерасход на полную сумму этих трат.
- Показатель обновляется сразу после:
  - сохранения лимитов;
  - добавления траты;
  - изменения суммы, категории или даты траты;
  - удаления траты.
- Траты с датами других месяцев не влияют на общий остаток текущего месяца.
- После F5 показатель заново рассчитывается из сохранённых лимитов и трат.
- Сумма отображается целыми тенге с пробелами между тысячами, например `90 500 ₸`.
- Показатель хорошо читается на телефоне шириной 375 px и не создаёт горизонтальную прокрутку.

## Примеры

- Общий бюджет `110 000 ₸`, расходы текущего месяца `19 500 ₸` → остаток бюджета `90 500 ₸`.
- Общий бюджет `110 000 ₸`, расходы текущего месяца `125 000 ₸` → «Перерасход бюджета: 15 000 ₸».
- Общий бюджет `0 ₸`, расходов нет → остаток бюджета `0 ₸`.
- Общий бюджет `0 ₸`, расходы текущего месяца `5 000 ₸` → «Перерасход бюджета: 5 000 ₸».
- Трата прошлого месяца `20 000 ₸` видна в списке, но не меняет остаток текущего месяца.

## Ограничения

- Использовать только HTML, CSS и JavaScript без библиотек, npm и внешних ресурсов.
- Все данные по-прежнему хранятся только в `localStorage` и никуда не отправляются.
- Не добавлять отдельный общий лимит: общий бюджет рассчитывается только как сумма лимитов категорий.
- Не добавлять выбор месяца, прогноз расходов, проценты и диаграммы.
- Не менять расчёт общего итога трат и отдельных категорий.
- Не ломать добавление, редактирование и удаление трат, лимиты и предупреждения по категориям.
- Никогда не показывать `NaN`.

## Готово, когда

- В разделе текущего месяца виден общий остаток бюджета в правильном денежном формате.
- При бюджете `110 000 ₸` и расходах `19 500 ₸` показывается `90 500 ₸`.
- При превышении общего бюджета показывается заметное предупреждение с точной суммой перерасхода, а отрицательное число не отображается.
- Сохранение лимитов сразу обновляет общий остаток.
- Добавление, изменение и удаление траты текущего месяца сразу обновляет общий остаток.
- Изменения трат других месяцев не влияют на показатель текущего месяца.
- После F5 значение рассчитывается правильно.
- При пустых или повреждённых данных не появляются ошибки и `NaN`.
- На ширине 375 px показатель полностью помещается на экране.
- В браузере нет ошибок JavaScript, все существующие функции работают как раньше.
